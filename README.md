# Dynamic Calculator

A simple dynamic calculator built using **HTML**, **CSS**, and **JavaScript**.  
This project performs basic arithmetic operations and demonstrates core frontend development concepts.

## 🚀 Features
- User-friendly interface
- Basic arithmetic operations (Addition, Subtraction, Multiplication, Division)
- Dynamic input handling using JavaScript
- Responsive layout using CSS
- Real-time calculation results

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## 📂 Project Structure
├── index.html
├── style.css
└── script.js

## 📌 How to Run the Project
1. Download or clone the repository
2. git clone https://github.com/sharanup593/simple-calculator.git
3. Open the project folder
4. Open `index.html` in any modern web browser

## 🎯 Purpose of the Project
This mini project was created to practice:
- JavaScript fundamentals
- DOM manipulation
- Event handling
- Frontend UI design using HTML and CSS
